# Site Acadêmico — Template

Este é um template simples de site acadêmico estático (HTML/CSS/JS) para você personalizar.

Como usar
1. Substitua os conteúdos:
   - index.html, about.html, publications.html, teaching.html, contact.html
   - Coloque sua foto em `assets/img/profile.jpg` (ou atualize o caminho).
   - Coloque seu CV em `cv.pdf` ou atualize o link em about.html.
2. Publicar:
   - GitHub Pages: crie um repositório, dê push no branch `main` (ou `gh-pages`) e ative GitHub Pages nas configurações.
   - Ou faça deploy em Netlify, Vercel ou qualquer host de arquivos estáticos.
3. Formulário de contato:
   - Atualmente o formulário usa `mailto:` como fallback. Para envio web automático, integre serviços como Formspree, Netlify Forms ou adicione um endpoint no seu servidor.
4. Personalizações possíveis (posso ajudar com qualquer uma):
   - Carregar publicações automaticamente via JSON/BibTeX.
   - Integração com ORCID/Lattes/Google Scholar.
   - Adição de páginas de projetos, datasets e repositório de slides.
   - Acessibilidade e SEO (metadados, Open Graph).
